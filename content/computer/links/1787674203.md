Opened VSCode to be surprised by a new UI. Seemed too forced with all text inside tabs being bold and dead space through thicker separators. Thankfully, it's an experimental flag that you can disable in the settings.

```json
{
  "experimental.workbench.modernUI": false
}
```

The GitHub issue shows that I'm not the only one feeling this way, but it's also surprising that this flag was enabled by default and not something you opt into.
